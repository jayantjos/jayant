# Electrical Reading Logbook

Android APK for electrician readings with Admin + Electrician roles.

- API server: http://187.127.158.193:8790
- 80 compulsory reading fields
- Admin-created electrician users
- Device approval
- Hourly / Daily / Monthly / Yearly reports
- GitHub Actions APK build
- Google Sheet sync support on server

No passwords or Google credentials are stored in this repository.
